# 金融数据工具

状态：已确认并实现 Cloudflare 第一版。

日期：2026-07-27

## 目标

通过远程网页和 Agent API 查看公开金融日频数据，并按明确日期范围进行同步。

## 第一版范围

- 首页只有金融数据工具，不保留虚假财富规划演示。
- 展示 D1 中的标的、数据类型、记录数、日期覆盖和最近抓取时间。
- 按名称、代码或类型搜索。
- 查看单个标的的日频明细。
- 同步前检查重叠记录，明确选择跳过或覆盖。
- 成功抓取的标准化批次归档到 R2，再写入 D1。
- 提供不依赖网页的远程 Agent API，以及网站中的独立接入说明页。
- preview 可以跨设备远程查看。
- 本地网页可以比较 local 与 preview D1，并在用户确认后单向传输缺少或冲突记录。

## 初始标的

| 名称 | 代码 | 类型 | 初始范围 |
|---|---|---|---|
| 上证指数 | `000001.XSHG` | 指数日 K | 最近 5 个已发布交易日 |
| 安信稳健增值混合 A | `001316.OF` | 公募基金净值 | 最近 5 个已发布净值日 |

“最近 5 日”按数据源已发布的数据日解释，不用周末或尚未发布净值的日期补空记录。

## 数据口径

- 日期按 Asia/Shanghai 自然日展示，D1 存 `YYYY-MM-DD`。
- 币种为 CNY。
- 价格、净值和成交额保存为十进制字符串，不使用 JavaScript 浮点数进行核心计算。
- 公募基金单位净值、累计净值和复权单位净值分别保存。
- 来源和 UTC 抓取时间随每条记录保存。

## 安全边界

- 只向公共数据源发送公开标的代码和日期范围。
- 不发送账户、持仓、成本、份额或其他个人财务数据。
- preview 的读取接口可远程访问。
- preview/production 同步写入默认关闭；启用后必须配置 `SYNC_TOKEN`。
- 环境复制只允许从本地服务通过 Cloudflare remote bindings 发起，不开放公网复制写接口。
- production 资源和部署仍需单独确认。

## UI 要求

- 使用 Tailwind CSS v4 与 shadcn/ui 组件。
- 采用紧凑、务实的数据工具布局，不使用装饰性大标题、渐变或无关动效。
- Mobile First；表格在窄屏允许横向滚动。
- 视觉和交互效果由用户自行查看，不要求 Agent 执行浏览器测试。

## 验收标准

- 首页显示两个初始标的及各 5 条 D1 数据。
- 搜索可以按名称或代码过滤。
- 选择标的能更新明细。
- 同步预检返回重叠条数。
- skip 不改写已有记录；overwrite 刷新相同键记录。
- 同步成功后页面更新，且 R2 存在对应归档对象。
- 环境对比区分一致、仅本地、仅远程和内容冲突。
- 缺少记录只新增；冲突必须明确选择本地或远程为准。
- 确认前后任一侧变化时，旧计划以 `SYNC_PLAN_STALE` 拒绝。
- 同域网页和远程 Agent API 可访问。
