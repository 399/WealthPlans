# 初始页面说明

状态：已确认用于技术基线，不代表最终产品范围。

日期：2026-07-25

首个页面用于验证 WealthPlans 的视觉方向、响应式布局和全栈连通性：

- 产品定位文案：让个人财富目标变得清晰、可追踪。
- 展示资产概览、目标进度和行动建议的示例视图。
- 所有金额和目标均明确标记为演示数据，不代表真实用户信息。
- 页面在 PC 与移动网页共用同一套 React 实现。
- 页面调用 `/api/v1/health` 展示本地 Worker 状态。
- 当前不包含账户、真实数据录入、财务建议、行情或第三方连接。

验收标准：

- 页面在常见桌面宽度和窄屏下布局完整。
- 键盘可访问主要按钮和导航。
- Worker 健康接口可用。
- local D1/R2 deep health 检查可用。
- 不需要任何线上 Cloudflare 资源即可运行。
